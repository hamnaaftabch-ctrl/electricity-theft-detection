# ⚡ Electricity Theft Detection using Machine Learning

A machine learning project to detect electricity theft from smart meter consumption data using the SGCC dataset.

## 🎯 Problem Statement
Electricity theft causes billions in losses globally. This project builds a classification system to flag suspicious consumption patterns automatically.

## 🛠️ Models Used
- Logistic Regression
- Random Forest Classifier

## 📊 Features Engineered
- Mean, Std, Min, Max usage
- IQR, Skewness, Kurtosis
- Zero days, Spike days, Trend slope
- Sudden drop/rise days

## 📈 Techniques Applied
- SMOTE for handling class imbalance (91.5% Normal vs 8.5% Theft)
- Stratified K-Fold Cross Validation
- ROC-AUC Curve Analysis
- Precision-Recall Curve

## 🧰 Libraries Used
- Python, Pandas, NumPy
- Scikit-learn, Imbalanced-learn
- Matplotlib, Seaborn
